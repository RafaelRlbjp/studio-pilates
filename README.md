# 🧘 Studio Pilates

Site responsivo desenvolvido para apresentar um Studio de Pilates, seus serviços, horários de funcionamento e facilitar o contato com clientes através do WhatsApp.

O projeto também permite solicitar uma aula experimental escolhendo uma data e um dos horários disponíveis.

## 📸 Sobre o projeto

O site foi desenvolvido com foco em uma navegação simples, visual agradável e facilidade de contato.

Entre as principais funcionalidades estão:

- Apresentação do Studio
- Seção de serviços
- Galeria de fotos
- Horários de funcionamento
- Solicitação de aula experimental
- Seleção de data e horário
- Bloqueio de finais de semana
- Controle de solicitações conforme horário de atendimento
- Validação para agendamentos no mesmo dia
- Contato para dúvidas através do WhatsApp
- Layout responsivo para computador, tablet e celular

> O horário escolhido pelo visitante representa uma solicitação. A confirmação da aula é realizada pelo Studio através do WhatsApp.
